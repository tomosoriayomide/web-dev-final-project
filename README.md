1. Project Overview

This project is a multi-page responsive website about space tourism. It provides users with information about destinations, booking options, and company details. It was built using HTML5, CSS3, and JavaScript without any frameworks.

2. Objectives

Design a visually appealing website.

Demonstrate semantic HTML structure.

Apply CSS3 transitions, animations, and responsiveness.

Add JavaScript interactivity (dynamic UI).

Deploy the website online ( Vercel).

3. Features

Homepage: Introduction to space tourism and hero section with call-to-action.

About Page: Information about the destinations and crew.


Responsive Design: Works on mobile, tablet, and desktop.

4. Tools & Technologies Used

HTML5 → For semantic structure.

CSS3 → For layout, animations, transitions, and responsiveness.

JavaScript (ES6) → For DOM interactivity (form validation, sliders, event handling).

Vercel → For hosting and deployment.

6. Implementation Details

CSS Animations/Transitions: Button hover effects, smooth page transitions, animated background.

JavaScript Functions:

Form validation (ensures correct input).

Image slider for destinations.

Responsive Layout: Achieved using media queries (@media).

7. Challenges & Solutions

Challenge: Making the site fully responsive.

Solution: Used CSS Flexbox & Media Queries.

Challenge: Adding interactivity without frameworks.

Solution: Implemented custom JavaScript functions.
